> [03-conversation.md](../guides/03-conversation.md) 의 **실행 편**입니다.
> 본 가이드가 "무엇을 말할지"라면, 이 문서는 "어디서 배울지"입니다.
>
> **대상**: 입문자 (히라가나부터) / **목표**: 캐주얼 모임 대화
> **투자 시간**: 하루 30~40분 × 4주

## ⚠️ 먼저 읽어주세요

- 아래 **채널 링크는 실제 채널 주소**입니다. 다만 유튜브 채널은 이름·핸들이 바뀔 수 있으니, 열리지 않으면 채널명으로 검색하세요.
- **개별 영상 링크는 일부러 넣지 않았습니다.** 영상은 비공개 전환·삭제가 잦아 링크가 금방 깨집니다. 대신 **검색어 링크**를 넣었으니 클릭하면 항상 최신 영상 목록이 나옵니다.
- 채널이 많다고 좋은 게 아닙니다. **§2의 "최소 구성 3채널"만 골라서 4주를 버티세요.** 채널 쇼핑은 공부가 아닙니다.

## 1. 유튜브로 일본어를 배울 때의 원칙

> 🎬 **영상으로 보기**: [유튜브 공부법](https://www.youtube.com/results?search_query=%EC%9C%A0%ED%8A%9C%EB%B8%8C%EB%A1%9C%20%EC%9D%BC%EB%B3%B8%EC%96%B4%20%EA%B3%B5%EB%B6%80%ED%95%98%EB%8A%94%20%EB%B2%95) · [섀도잉 방법](https://www.youtube.com/results?search_query=%EC%84%80%EB%8F%84%EC%9E%89%20%ED%95%98%EB%8A%94%20%EB%B2%95%20%EC%9D%BC%EB%B3%B8%EC%96%B4)

### 원칙 ①: 채널 수를 줄이세요

> 🎬 [공부법](https://www.youtube.com/results?search_query=%EC%9C%A0%ED%8A%9C%EB%B8%8C%EB%A1%9C%20%EC%9D%BC%EB%B3%B8%EC%96%B4%20%EA%B3%B5%EB%B6%80%ED%95%98%EB%8A%94%20%EB%B2%95)

입문자가 실패하는 가장 흔한 패턴은 **좋아 보이는 채널을 20개 구독하고 아무것도 안 보는 것**입니다.

```text
한국어 설명 채널 1개  ← 문법·문자 (이해용)
일본어 인풋 채널  1개  ← 귀 만들기 (노출용)
실전 회화 채널   1개  ← 리액션·뉘앙스 (모방용)
────────────────────
합계 3개. 이게 전부입니다.
```

### 원칙 ②: "보는 것"과 "훈련하는 것"을 구분하세요

> 🎬 [섀도잉](https://www.youtube.com/results?search_query=%EC%84%80%EB%8F%84%EC%9E%89%20%ED%95%98%EB%8A%94%20%EB%B2%95%20%EC%9D%BC%EB%B3%B8%EC%96%B4)

| 활동 | 효과 | 하루 배분 |
| --- | --- | --- |
| 그냥 보기 (자막 켜고 감상) | 낮음 — 공부한 기분만 남음 | 10분 |
| **소리 내어 따라 하기 (섀도잉)** | **높음** | **15분** |
| **일시정지하고 내 대답 말해보기** | **가장 높음** | **10분** |

👉 **입을 안 움직인 시간은 공부 시간이 아닙니다.** 유튜브는 수동적으로 보게 만드는 매체라, 의식적으로 소리를 내야 합니다.

### 원칙 ③: 같은 영상을 반복하세요

새 영상 10개 < 같은 영상 10번. 입문 단계에서는 **한 영상을 씹어먹는 쪽**이 훨씬 빠릅니다.

> 🔥 **3주차 핵심 훈련법 — "아이즈치 더빙"**
>
> 1. 일본인 두 명이 대화하는 영상을 켠다
> 2. **듣는 사람 역할**을 내가 맡는다
> 3. 말하는 사람이 끊길 때마다 `うん` `そうなんですね` `へえ〜` `なるほど` 를 **내 입으로** 넣는다
> 4. 같은 영상으로 5회 반복
>
> 이걸 일주일 하면 실전에서 **뇌를 거치지 않고** 리액션이 나옵니다. 이 문서에서 제일 효과 좋은 훈련입니다.

## 5. 유튜브 200% 활용법

> 🎬 **영상으로 보기**: [재생속도·자막 설정](https://www.youtube.com/results?search_query=%EC%9C%A0%ED%8A%9C%EB%B8%8C%20%EC%9E%AC%EC%83%9D%EC%86%8D%EB%8F%84%20%EC%9E%90%EB%A7%89%20%EC%84%A4%EC%A0%95) · [구간 반복 설정](https://www.youtube.com/results?search_query=%EC%9C%A0%ED%8A%9C%EB%B8%8C%20%EB%B0%98%EB%B3%B5%20%EC%9E%AC%EC%83%9D%20%EA%B5%AC%EA%B0%84%20%EC%84%A4%EC%A0%95)

### 재생 설정 (모르면 손해)

> 🎬 [자막 재생속도](https://www.youtube.com/results?search_query=%EC%9C%A0%ED%8A%9C%EB%B8%8C%20%EC%9E%AC%EC%83%9D%EC%86%8D%EB%8F%84%20%EC%9E%90%EB%A7%89%20%EC%84%A4%EC%A0%95)

| 기능 | 방법 | 왜 |
| --- | --- | --- |
| **재생 속도 0.75배** | 톱니바퀴 → 재생 속도 | 입문자에겐 원속도가 너무 빠름. 익숙해지면 1.0 → 1.25로 |
| **일본어 자막 켜기** | 자막(CC) → 일본어 | 한국어 자막만 보면 **귀가 안 늘어납니다** |
| **자막 껐다 켜기 반복** | — | 끄고 듣기 → 켜서 확인 → 다시 끄고 듣기 |
| **구간 반복** | 영상 우클릭 → 반복 재생 | 30초 구간을 반복 재생 |
| **10초 되감기** | `←` 키 / 화면 왼쪽 더블탭 | 섀도잉 필수 |

### 나만의 재생목록 만들기 (강력 추천)

```text
📁 01_히라가나        ← 1주차. 끝나면 안 봄
📁 02_자기소개        ← 2주차
📁 03_아이즈치 ⭐     ← 3주차. 모임 가기 전 차 안에서 다시 봄
📁 04_문화·매너
📁 99_모임 직전 5분   ← 여기에 3~5개만. 실전 직전 복습용
```

특히 **「99_모임 직전 5분」** 재생목록을 만들어 두세요. 모임 가는 지하철에서 이것만 돌리면 됩니다.

| 함정 | 왜 문제인가 | 대신 |
| --- | --- | --- |
| 채널 20개 구독 | 뭘 볼지 고르다 시간 다 감 | 3개로 제한 |
| 한국어 자막만 보기 | 읽기 연습일 뿐 듣기가 안 늚 | 일본어 자막 병행 |
| JLPT 문법 강의부터 | 시험용 문법 ≠ 모임 회화 | 회화·리액션 우선 |
| 매일 새 영상 | 정착이 안 됨 | 같은 영상 반복 |
| 소리 안 내고 보기 | 입이 안 열림 | 무조건 소리 내기 |
| 애니메이션으로 회화 배우기 | **애니 말투는 실생활에서 이상합니다** (`だぜ` `〜のだ` 등) | 인터뷰·브이로그 |

> ⚠️ **애니메이션 주의**: 듣기 노출로는 훌륭하지만, **말투를 그대로 따라 하면 안 됩니다.** 애니 캐릭터 말투로 초면에 말하면 일본인 입장에서 상당히 이상합니다. 실제 사람이 나오는 인터뷰·브이로그를 모방 대상으로 삼으세요.
