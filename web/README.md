# web/ — 모바일 현장 카드

폰에서 한 손으로 쓰는 페이지입니다. `index.html` 한 파일로 완결돼 있어 빌드가 필요 없습니다.

## 무엇을 하는가

- **일본어가 가장 크게** 표시되고, 아래에 후리가나(가나 전사), 그 아래에 한글 읽기가 작게 붙습니다
- 헤더의 **「한글 읽기」 버튼을 끄면** 한글이 사라집니다 → **읽기 훈련 모드.** 설정은 저장됩니다
- 문장을 **탭하면 일본어가 화면 가득** 뜹니다 → **폰을 돌려서 상대에게 보여주세요**
- 한국어로 검색됩니다 (`얼마`, `추천`, `건배`…)
- 장면별 탭: 만능 · 이자카야 · 리액션 · 위기 · 골프 · 식당·편의점 · 교통 · 읽기 · 안전
- 섹션마다 **유튜브 검색 링크**가 붙어 있습니다 (개별 영상이 아니라 검색어 — 링크가 안 깨집니다)
- **영상** 탭에 채널 카탈로그 15곳 + 아이즈치 더빙 훈련법
- 다크/라이트 모두 대응. 어두운 가게에서도 읽힙니다

## 배포

GitHub Pages로 공개하려면:

```
Settings → Pages → Source: main / (root)
```

이후 주소: `https://mbshin.github.io/japanese-izakaya-guide/web/`

로컬 확인:

```bash
python3 -m http.server 8000
# http://localhost:8000/web/
```

## 내용을 고칠 때

문장은 `index.html` 안의 `const DATA = [...]` 배열에 있습니다.

| 키 | 형식 |
| --- | --- |
| `items` | `['한글 읽기', '일본어', '뜻', 우선순위 0~3]` |
| `heard` | `['읽기', '일본어', '뜻', '내 대답']` — 점원이 묻는 말 |
| `yt` | `['라벨', '유튜브 검색어']` — 섹션 상단 칩 |
| `chans` | `['채널명', '설명', 'URL', 별점]` |
| `chips` | `['한자', '읽기', '뜻', 강조여부]` |

`../data/phrases.json` 은 이 배열에서 추출한 것입니다. 문장을 고쳤다면 다시 추출하세요.
