## 쓰는 법

**일본어를 먼저 보세요.** 한글 읽기는 막힐 때만 보는 보조 장치입니다.

| 칸 | 용도 |
| --- | --- |
| **일본어** (굵게) | 상대에게 화면으로 보여주는 칸. **눈으로 먼저 읽어보세요** |
| 아래 줄 (かな) | 한자를 가나로 푼 것. 여기까지 읽히면 절반은 된 겁니다 |
| 한글 읽기 | 막힐 때만. 계속 여기만 보면 글자가 늘지 않습니다 |
| 뜻 | 무슨 말인지 |

### 읽기 훈련하는 법

```text
1주차   일본어 → 가나 → 한글 읽기 순으로 눈이 간다
2주차   가나까지만 보고 소리 낸다. 한글은 확인용
3주차   한자 줄만 보고 소리 낸다. 막히면 가나
```

- `-` 는 **한 박자 길게 끄는 소리**입니다. `아리가토-` → 「아리가토오」
- 일본어는 한국어보다 **억양이 평평**합니다. 문장 끝을 내리세요
- 글자를 제대로 배우려면 → [../guides/04-kana.md](../guides/04-kana.md)

--- | --- |
| **한글 읽기** | **내가 소리 내어 읽는 칸.** 이것만 보고 말하면 됩니다 |
| 일본어 | 안 통할 때 **화면을 상대에게 보여주는 칸** |
| 뜻 | 무슨 말인지 |

- `-` 는 **한 박자 길게 끄는 소리**입니다. `아리가토-` → 「아리가토오」, `큐-` → 「큐우」.
  일본어는 길이가 뜻을 바꿉니다. 짧게 끊지 마세요.
- 일본어는 한국어보다 **억양이 평평**합니다. 문장 끝을 내리세요.
- 글자를 배우고 싶으면 → [04-kana.md](../guides/04-kana.md)

> 🎬 [여행 필수 표현](https://www.youtube.com/results?search_query=%EC%9D%BC%EB%B3%B8%20%EC%97%AC%ED%96%89%20%ED%9A%8C%ED%99%94%20%ED%95%84%EC%88%98%20%ED%91%9C%ED%98%84) · [스미마셍 쓰임](https://www.youtube.com/results?search_query=%EC%9D%BC%EB%B3%B8%EC%96%B4%20%EC%8A%A4%EB%AF%B8%EB%A7%88%EC%85%8D%20%EC%82%AC%EC%9A%A9%EB%B2%95)

| 일본어 | 한글 읽기 | 뜻 |
| --- | --- | --- |
| **すみません** | 스미마셍 | 저기요 / 죄송 / 감사 ★최다 사용 |
| **これ、お願いします**<br>これ、おねがいします | 코레, 오네가이시마스 | 이거 주세요 (가리키며) |
| **いくらですか？** | 이쿠라데스카? | 얼마예요? |
| **○○はどこですか？** | ○○와 도코데스카? | ○○는 어디예요? |
