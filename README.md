## 💡 세 문장으로 요약

1. **가게 선택이 일본어 실력보다 중요합니다** — 立ち飲み屋·横丁·카운터석. 체인 이자카야 ❌
2. **혼자 가고, 폰을 보지 마세요** — 이 둘만으로 말을 걸어오는 확률이 몇 배가 됩니다
3. **마스터부터 공략하세요** — 거절당할 위험이 없고, 다른 손님으로 가는 다리입니다

그리고 **호객꾼(客引き)은 절대 따라가지 마세요.**
