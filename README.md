**왜 이 순서인가**

```text
네트워킹(01)  ← 목표. 여기가 안 되면 나머지는 의미 없음
   ↑
대화 엔진(02) ← 목표를 굴리는 힘. 아이즈치가 없으면 대화가 끊김
   ↑
글자(03)      ← 있으면 훨씬 빨라지지만, 00의 한글 읽기로 우회 가능
   ↑
여행(04)      ← 네트워킹과 별개 트랙. 이동·식사가 되게 하는 배경
```

> 각 문서의 섹션마다 **🎬 유튜브 검색 링크**가 붙어 있습니다. 설명이 이해 안 되면 바로 영상으로 넘어가세요.

## 🎯 읽는 순서

목적이 **여행 중 이자카야 네트워킹**이므로, 전부 읽을 필요는 없습니다.

> ✍️ **글자를 아직 못 읽어도 시작할 수 있습니다.**
> [00-cheatsheet.md](./00-cheatsheet.md) 는 **한글 읽기**가 앞 칸에 있어서, 그것만 보고 소리 내면 됩니다.
> 글자 공부([03-kana.md](./03-kana.md))는 병행하거나 나중에 해도 됩니다.

### 0단계 — 오늘 당장

```text
00-cheatsheet.md  한글 읽기만 보고 소리 내어 읽어보기 (10분)
```

### 1단계 — 목표부터 확인

```text
01-izakaya.md   전체 정독
  §1  가게 선택      ★★★  성패의 80%
  §4  말 거는 법     ★★
  §5  마스터 공략    ★★
  §11 안전 (호객꾼)  ★★  반드시
```

### 2단계 — 대화가 굴러가게

```text
02-conversation.md
  §7  아이즈치(맞장구)  ★★★  여기가 진짜 핵심
  §9  위기 탈출 표현
  §6  자기소개 15초
  §10 존댓말/반말
```

### 3단계 — 글자 (병행 가능)

```text
03-kana.md     히라가나 3~5일 + 가타카나 2~3일. 쓰기 말고 읽기만
               내 이름 가타카나 표기는 1순위로 확정할 것
```

### 4단계 — 여행 자체가 되게

```text
04-travel.md
  §3  간판 한자        ★  한국인의 특권. 하루면 끝
  §4  숫자             ★  못 알아듣는 것의 대부분
  §2  만능 문장 10개
```

### 5단계 — 훈련

```text
90-youtube.md  3주차 「아이즈치 더빙」 훈련이 효과 최고
```

> ⏱️ **시간이 없다면**: [00-cheatsheet.md](./00-cheatsheet.md) 한 장만 캡처해서 폰에 넣으세요.

## 💡 세 문장으로 요약

1. **가게 선택이 일본어 실력보다 중요합니다** — 立ち飲み屋·横丁·카운터석. 체인 이자카야 ❌
2. **혼자 가고, 폰을 보지 마세요** — 이 둘만으로 말을 걸어오는 확률이 몇 배가 됩니다
3. **마스터부터 공략하세요** — 거절당할 위험이 없고, 다른 손님으로 가는 다리입니다

그리고 **호객꾼(客引き)은 절대 따라가지 마세요.**
