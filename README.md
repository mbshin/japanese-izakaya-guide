### 왜 이 순서인가

```text
   네트워킹  ①이자카야   ②골프      ← 목표. 여기가 안 되면 나머지는 의미 없음
                  ↑
```

## 🎯 읽는 순서

> ✍️ **글자를 아직 못 읽어도 시작할 수 있습니다.**
> 모든 문장은 **일본어 → 후리가나 → 한글 읽기** 3단으로 되어 있습니다.
> 처음엔 한글만 보고 말해도 되지만, **목표는 한자 줄만 보고 소리 내는 것**입니다.

### 0단계 — 오늘 당장 (10분)

```text
field/say.md   한글 읽기를 보고 소리 내되, 위의 일본어를 눈으로 따라가기
```

**읽기 훈련 3주 경로**

```text
1주차   일본어 → 가나 → 한글 읽기 순으로 눈이 간다
2주차   가나까지만 보고 소리 낸다. 한글은 확인용
3주차   한자 줄만 보고 소리 낸다. 막히면 가나
```

> 📱 모바일 카드([web/](./web/))에서는 **「한글 읽기」 버튼을 끄면** 한글이 사라집니다. 그게 훈련 모드입니다.

### 1단계 — 목표 장면 확인

```text
guides/01-izakaya.md   §1  가게 선택      ★★★  성패의 80%
                 §4  말 거는 법     ★★
                 §5  마스터 공략    ★★
                 §11 안전 (호객꾼)  ★★  반드시

guides/02-golf.md      §1  1人予約        ★★★  혼자 예약 → 모르는 3명과 한 조
                 §5  라운드 중 표현  ★★  「ナイスショット！」면 충분
                 §6  하프타임 점심   ★★  최대 골든타임
```

### 2단계 — 대화가 굴러가게

```text
guides/03-conversation.md
  §7  아이즈치(맞장구)  ★★★  여기가 진짜 핵심
  §9  위기 탈출 표현
  §6  자기소개 15초
  §10 존댓말/반말
  §14 칭찬과 호감 표현   ★  「ちょっと…」가 거절이라는 것만은 꼭
```

### 3단계 — 글자 (병행 가능)

```text
guides/04-kana.md   히라가나 3~5일 + 가타카나 2~3일. 쓰기 말고 읽기만
               내 이름 가타카나 표기는 1순위로 확정할 것
```

### 4단계 — 여행 자체가 되게

```text
guides/05-travel.md   §3 간판 한자 · §4 숫자 · §2 만능 문장 10개
```

### 5단계 — 훈련

```text
resources/youtube.md   3주차 「아이즈치 더빙」 훈련이 효과 최고
```

> ⏱️ **시간이 없다면**: [field/say.md](./field/say.md) 한 장만 캡처해서 폰에 넣으세요.

## 🍺⛳ 두 네트워킹 채널 비교

| | 이자카야 | 골프 |
| --- | --- | --- |
| 준비 | 없음 — 오늘 밤 바로 가능 | 예약·복장·장비 |
| 비용 | 3~5천 엔 | 6천~1.5만 엔 |
| 함께 있는 시간 | 1~2시간 | **6~8시간** |
| 말 걸기 | 내가 먼저 해야 함 | **이미 같은 조** |
| 일본어 부담 | 중간 | **낮음** (용어가 가타카나 영어) |
| 관계 깊이 | 얕음~중간 | **깊음** |

> 💡 **둘 다 "혼자 가기"가 핵심입니다.** 일행이 있으면 현지인이 끼어들 틈이 없습니다.

## ✅ 출발 전 최소 준비

```text
□ field/say.md · field/see.md 캡처해서 폰 앨범 맨 앞에
□ LINE 계정 + QR 코드 화면 위치 숙지
□ 「それ、おいしそうですね。何ですか？」 암기   ← 이자카야 첫 마디
□ 「ナイスショット！」「ドンマイ！」 암기        ← 골프 필수 2개
□ 「日本語、まだ下手なんですけど…」 암기        ← 방어막
□ 아이즈치 6개 반사적으로 나오게
□ 모바일 Suica/PASMO 발급
□ Visit Japan Web 등록 (착륙 6시간 전까지)
□ 갈 가게 3곳 미리 저장 (立ち飲み / 카운터석 있는 곳)
□ 골프 갈 거면 — 1人予約 예약 + 재킷 챙기기
□ 현금 준비 (작은 가게는 現金のみ 많음)
```

## 💡 네 문장으로 요약

1. **장소 선택이 일본어 실력보다 중요합니다** — 立ち飲み屋·横丁·카운터석. 체인 이자카야 ❌
2. **혼자 가고, 폰을 보지 마세요** — 이 둘만으로 말을 걸어오는 확률이 몇 배가 됩니다
3. **마스터부터 공략하세요** — 거절당할 위험이 없고, 다른 손님으로 가는 다리입니다
4. **골프의 1人予約을 쓰세요** — 5시간 동행이 자동으로 만들어집니다

그리고 **호객꾼(客引き)은 절대 따라가지 마세요.**
